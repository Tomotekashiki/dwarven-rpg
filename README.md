# Dwarven RPG - Mobile PWA & Web Edition

Authentic native Flash RPG ported to modern Web & Mobile via Ruffle WebAssembly emulator.

## Features
- 📱 **Mobile PWA Support**: Installable as a standalone app on iOS Safari and Android Chrome.
- ⚡ **Offline Gameplay**: Powered by Service Worker caching (`sw.js`).
- 🎮 **Touch Controls**: Point-and-click / tap-to-attack touch emulation.
- 🔄 **Landscape Optimization**: Native landscape layout with rotate prompt for mobile.
- 🔊 **Auto Audio Unlock**: Web Audio context unlocked seamlessly on first touch.

## Deploy on Vercel
1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** / **Static Site**.
3. Output Directory: Leave as `.` (root).
4. Click **Deploy**.
